# Lark 多账号群活跃中控面板

纯静态 HTML 单页应用，用于快速管理和跳转多个 Lark 账号的群聊，适配多账号群活跃场景。

## 功能特性

- **一键跳转群聊**：点击卡片唤起本地 Lark 客户端，自动切换账号打开目标群
- **可视化配置**：网页内直接新增/编辑/删除账号群组，无需修改源码
- **标签系统**：自定义标签文字和颜色，支持多标签组合筛选
- **账号状态**：正常 / 待核验 / 链接失效 三种状态，侧边颜色标识
- **活跃记录**：一键标记活跃时间，支持按最久未活跃排序
- **批量操作**：多选批量标记活跃、批量置顶、批量删除
- **数据备份**：导出 JSON 备份，支持追加/覆盖两种导入模式
- **暗色模式**：浅色/暗色主题切换，本地保存偏好
- **快捷键**：`Ctrl+K` 聚焦搜索，`Ctrl+S` 快速新增，`ESC` 关闭弹窗

## 使用前提

1. 本机 Lark 客户端已提前登录对应账号
2. 账号已加入目标群
3. 跳转链接必须使用 `chat/open` 格式：
   ```
   https://applink.larksuite.com/client/chat/open?chat_id=oc_xxxxxxx
   ```
   > 注意：入群邀请链接（`add_by_link`）无法直接打开群聊

## 快速开始

直接用浏览器打开 `index.html` 即可使用，无需安装任何依赖。

### 部署到公网（可选）

将 `index.html` 上传到任意静态托管平台：
- Cloudflare Pages
- Vercel
- GitHub Pages
- Netlify

部署后将链接分享给团队成员即可使用。

## 数据存储

所有配置数据保存在浏览器 `localStorage` 中：
- 清除浏览器缓存会丢失数据
- 建议定期使用「导出备份」功能保存 JSON
- 换设备时使用「导入配置」恢复数据

## 数据结构

```json
{
  "name": "账号001 | 闲聊大群A",
  "descShort": "早中晚定时活跃",
  "desc": "活跃时段：9点、14点、20点",
  "tags": [
    {"label": "🔥高活跃", "colorBg": "#dcfce7", "colorText": "#166534"}
  ],
  "isTop": true,
  "link": "https://applink.larksuite.com/client/chat/open?chat_id=oc_xxxxxxx",
  "status": "ok",
  "lastActiveTime": "2026-10-12T10:00:00.000Z"
}
```

### 状态字段说明

| status | 说明 |
|--------|------|
| `ok` | ✅ 正常 |
| `wait` | ⚠️ 待核验 |
| `invalid` | ❌ 链接失效 |

## 注意事项

- 本工具仅做 Lark 群跳转中控，**不会自动发送消息**
- 多账号批量群互动请留意 Lark 风控策略，避免账号受限
- 所有配置保存在浏览器本地，不会上传到任何服务器
